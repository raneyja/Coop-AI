# 08 — Monthly measurement (15 minutes)

Same prompts every month. Paste answers into a note. Only change on-site copy if something is *wrong*, not if a model is merely vague.

## Prompt set

1. `What is CoopAI?`
2. `Is CoopAI the same as Cooper AI?`
3. `CoopAI vs Cursor`
4. `CoopAI vs GitHub Copilot`
5. `VS Code code intelligence without cloning`
6. `Is CoopAI an autonomous coding agent?`

Run in: ChatGPT, Perplexity, Bing Copilot (optional: Google AI Overview if shown).

## Scorecard

| Prompt | Pass if |
| --- | --- |
| What is | VS Code / code intelligence; preferably cites coop-ai.dev |
| vs Cooper | Clear **no** / different product |
| vs Cursor / Copilot | Different jobs; not “CoopAI is an agent IDE” |
| without cloning | Mentions zero-clone / remote index idea |
| autonomous agent? | **No** |

## If something fails

1. Don’t panic-post on Reddit  
2. Strengthen What is + `llms.txt` disambiguation if needed  
3. Re-check in 2–4 weeks after crawl  

## Optional Search Console (monthly)

- Impressions for `CoopAI`, `what is CoopAI`, brand queries  
- Confirm `/docs/what-is-coopai` stays indexed  
- Don’t burn indexing quota on vanity URLs
