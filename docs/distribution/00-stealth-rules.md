# 00 — Stealth rules

## Hard no

- Personal LinkedIn, personal X/Twitter under your real name, “side project while at [employer]”
- Screenshots that show employer Slack/Jira/GitHub orgs
- Using your work email for Product Hunt, Reddit, Marketplace publisher, or HN
- Connecting CoopAI publicly to your day job, teammates, or internal repos

## Hard yes

- Publish as **CoopAI** (brand), or a dedicated anonymous handle used only for CoopAI
- Use `support@coop-ai.dev` / brand accounts
- Link to **https://coop-ai.dev** and **https://coop-ai.dev/docs/what-is-coopai**
- Stay boringly accurate: VS Code code intelligence, not an autonomous agent

## Before you post anywhere public

Ask:

1. Could a coworker reverse this to me in 60 seconds?
2. Does this mention my employer even indirectly?
3. Is the account email / username personal?

If any answer is risky → skip that channel.

## Preferred voice

- First person plural or brand: “CoopAI…”, “we built…”
- Not: “I left my FAANG job to…”
- Disambiguate once when useful: “Not Cooper AI — different product.”
