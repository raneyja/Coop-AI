## Failure and root cause

The original Documenso answer listed two dependency edges but explored only the target file. It acknowledged that both caller bodies were missing, then asserted sole status enforcement and downstream signature/audit consequences. It also misplaced the PENDING guard. A graph edge establishes a file relationship; it cannot establish the caller's inline checks, middleware policy, or a conditional database operation.

The old Blast hot path gathered dependency metadata and asynchronous job output without retaining caller bodies in `BlastRadiusEvidence`. The synthesis prompt serialized paths, graph details, and risk guidance. Its evidence card could label graph evidence Strong without distinguishing behavioral coverage. These conditions let graph adjacency become an operational claim.

## Implemented repair

- `src/context/blastRadiusSourceEvidence.ts` owns the bounded gather. It reads the complete remote target and the graph concurrently, ranks and opens at most three dependent bodies, and retains completed reads before the existing soft gather deadline. Every read uses `IndexedRepoWorkspace.readFile` with the turn's frozen repository/ref. Local or wrong-repository bodies are rejected. Truncation and missing bodies remain explicit limitations.
- `src/chat/CoopChatSession.ts` calls that gather on the `/blast` path, records each actual read in activity and diagnostics, and prevents a second job gather from overwriting or repeating it. Numbered source bodies reach synthesis once; diagnostics record whether each body survived serialization. Selected ranges retain their focus while the target body expands to inspect later checks.
- `src/prompts/blastRadiusSynthesis.ts` requires actual call sites, earlier caller rejects/filters/helper calls, remaining target guards, and conditional writes. Unread helpers and middleware remain unknown. The answer enrichment protects exact code fences and preserves neighboring verified sentences while replacing unsupported access, sole-enforcement, and stored-invariant claims.
- `src/webview/evidenceCardSummary.ts` reserves Strong behavioral evidence for a full target and full bodies for every listed dependent, with a trusted graph. Graph-only, missing, and truncated bodies keep a coverage limitation.
- Blast retains the assigned model's reasoning phase for control-flow analysis. A trial without reasoning produced faster but insufficiently grounded answers and was reverted. The existing response clock and user Stop behavior remain in place.

The shared checkout contains other ongoing repairs. This run did not commit, push, or create a PR. Jon approved the scoped backend deployment described below. It did not reopen historical billing, sign-in, autocomplete, Stop, or `/edit` qualification.
