# CoopAI

Zero-clone code intelligence sidebar for VS Code.

## Install from VSIX

1. Command Palette → **Extensions: Install from VSIX…**
2. Choose the `.vsix` built with `npm run package`.
3. Reload VS Code and open the CoopAI activity-bar icon.

## Develop

See the Coop-AI repository docs for Extension Development Host launch and API setup.
